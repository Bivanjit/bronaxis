## What this version is

This is the **frontend-first build**.

It intentionally uses:
- Plain HTML
- One CSS file
- One small JavaScript file
- Local image assets

No React, no Tailwind, no animation library, no unnecessary dependencies.

The goal is simple: readable code, fast loading, easy editing and a professional result.
